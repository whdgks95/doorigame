# 두리게임 (doorigame)

둘이 하는 두뇌 게임 사이트. 더 지니어스·피의 게임에 나온 1:1 게임을 링크 하나로 친구와 바로 즐길 수 있습니다.

## 들어 있는 게임

| 프로그램 | 게임 | 비고 |
|---|---|---|
| 더 지니어스 | 흑과 백 | 99점, 9라운드, 흑(0~9)/백(10+) 정보만 공개, 램프 5개 |
| 더 지니어스 | 결! 합! | 9장 타일, 합 +1 / 결 +3 / 오답 -1, 3라운드(동점 시 연장) |
| 더 지니어스 | 인디언 포커 | 1~10 두 벌, 칩 30개, 10 들고 다이하면 벌칙 10, 턴 30초 (초과 시 자동 다이/체크) |
| 더 지니어스 | 미스터리 사인 | 매 라운드 규칙·문제 무작위 출제(규칙 28종), 숫자 내서 힌트 → 정답 +1/오답 -1, 둘 다 패스하면 다음 힌트(힌트당 최대 3분, 라운드당 힌트 최대 8개), 11라운드 |
| 더 지니어스 | 십이장기 | 3×4 판, 포로 놓기, 왕 잡기 / 적진 버티기 승리 |
| 피의 게임 | 미스터리 넘버 | 다빈치 코드 규칙 |
| 피의 게임 | 시크릿 다이스 | 딜러 주사위 3개 중 1~3개 고정 → 서로 숫자를 숨겨 내서 5개 완성 → 주 플레이어가 족보 기록 (3개 고정은 1회) |

## 동작 방식
- 홈: 왼쪽 게임 목록, 오른쪽에 **방 만들기**와 플레이 방법
- 방 만들기를 누르면 `/r/방번호` 주소의 방이 생기고, **링크 복사** 버튼으로 주소를 복사할 수 있어요
- 링크로 들어온 사람이 두 번째 자리를 차지하면 바로 게임 시작
- 세 번째 사람이 들어오면 **"방이 가득 찼어요 (2/2)"** 화면이 뜨고 입장이 막혀요
- 새로고침하거나 잠깐 연결이 끊겨도 같은 브라우저면 자기 자리로 돌아와요
- 게임이 끝나면 두 사람 모두 **다시 하기**를 누르면 새 판 시작
- 상대에게 보이면 안 되는 정보(내 인디언 포커 카드, 흑과 백 점수, 다빈치 숨긴 숫자)는 서버가 아예 보내지 않아요

## 턴 타이머
게임 상태에 `deadline`이 있으면 서버가 시간 초과 시 `game.timeout()`으로 자동 진행합니다. 인디언 포커 30초, 시크릿 다이스 40초 (`TURN_MS` 상수로 조정).

## 시크릿 다이스 점수 조정
`games/secretdice.js`의 `SPECIAL` 상수에서 족보 점수를 바꿀 수 있어요. 방송 기록상 2·3 다이스·4연속·4 다이스·조커는 20점이고, 5연속(30)과 5 다이스(50)는 임의로 정한 값입니다.

## 내 컴퓨터에서 실행
```bash
npm install
npm start
# http://localhost:3000 접속
```
같은 브라우저 두 탭은 같은 사람으로 인식돼요. 혼자 테스트할 때는 **일반 창 + 시크릿 창**으로 들어가세요.

## 인터넷에 올리기 (예: Render)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. https://render.com → New → **Web Service** → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start`
4. 배포가 끝나면 `https://xxxx.onrender.com` 주소가 생깁니다.

> 무료 플랜은 15분 동안 접속이 없으면 서버가 잠들어서 첫 접속이 30초쯤 느리고, 잠들 때 진행 중이던 방은 사라집니다. 계속 켜 두려면 유료 플랜(월 7달러 정도)을 쓰세요. Railway, Fly.io도 같은 방식으로 올릴 수 있습니다(웹소켓 지원 필요).

## doorigame.com 연결
1. 가비아, Cloudflare, Namecheap 등에서 `doorigame.com` 도메인을 구매합니다. 먼저 구매할 수 있는지 확인하세요.
2. Render 서비스 → Settings → **Custom Domains**에 `doorigame.com`과 `www.doorigame.com`을 추가합니다.
3. 도메인 업체 DNS 설정에서 Render가 알려주는 레코드(보통 `A` 또는 `CNAME`)를 등록합니다.
4. 몇 분~몇 시간 뒤 https://doorigame.com 으로 접속됩니다. HTTPS 인증서는 Render가 자동으로 붙여요.

## 게임 추가하는 법
1. `games/새게임.js` 작성: `init()`, `action(state, 플레이어번호, 행동)`, `view(state, 플레이어번호)`
2. `games/index.js`에 등록
3. `public/meta.js`에 이름과 도움말 추가, `public/renderers.js`에 화면 함수 추가

## 구조
```
server.js          방 관리 + 실시간 통신 (Express + Socket.io)
games/             게임 규칙 (서버에서만 판정)
public/index.html  홈 (게임 목록 / 방 만들기)
public/room.html   대결방
public/room.js     입장, 링크 복사, 만원 처리, 다시 하기
public/renderers.js 게임별 화면
public/meta.js     게임 목록 + 플레이 방법
```
